# i-luncher 설치 파일

배포 패키지의 `Install.cmd`를 실행하면 패키지 전체를 현재 사용자의 `%LOCALAPPDATA%\i-luncher\Releases\<버전>`에 한 번 복사하고 시작 메뉴에 **i-luncher** 바로가기를 만듭니다. 관리자 권한, .NET SDK, 인터넷 연결은 필요하지 않습니다.

설치된 프로그램은 `i-luncher.exe` 하나와 네 도구의 DLL, 공통 .NET 런타임으로 구성됩니다. 일반 도구는 런처 프로세스 안에서 바로 창을 열며 실행 중에 추가로 빌드하거나 설치하지 않습니다. DiskAtlas는 같은 실행 파일의 `--app disk-atlas` 모드로 시작하며 디스크 직접 읽기에 필요한 권한을 받기 위해 Windows 관리자 권한 확인을 표시합니다.

설치 과정은 앱 데이터나 이전 릴리스를 삭제하지 않습니다. 같은 버전은 내용이 같을 때만 다시 사용할 수 있으며, 배포 파일 검증이나 복사가 실패하면 기존 설치와 시작 메뉴 바로가기를 유지합니다.
